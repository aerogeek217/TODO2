### registerOpenEditor, editorsHoldChanges, leaveOpenEditors, afterLeavingEditors, OpenEditor, layoutLeaveAsks, leaveLayout, quitLayoutEditors — stores/editor-leave.ts

The open editor dialogs that hold a copy until their Save (Edit list, the Number / chart / Created vs completed editors), as the rest of the app sees them — the one rule that nothing leaves one with changes without its question. An editor registers `{ changed(), ask() }` while mounted (`hooks/use-editor-leave`); `afterLeavingEditors(run)` runs at once when none holds changes, else asks each in turn (`leaveOpenEditors`) and runs only once all were saved or discarded (never on Keep editing). Used by `ui-store.openSettings` / `openListEditor` / `openNumberEditor`, `chart-widgets-store.openEditor` / `openTrendEditor`, `workspace-store.load` / `createLayout` / `duplicateLayout` / `delete` (the open layout), `widget-hooks.openEditList` / `openNumberEditor` / `addWidgetAt`, `AddWidgetFlow` (adding a widget asks first — the palette's Add Widget › and a menu run by the keys reach it with an editor still open), `FilledCell` and the phone's `MobileCell` (a tab switched or closed, Collapse / Expand row, the menu's Split cell, Merge with, Insert row / column, Remove widget and Close cell) and `cell-menu` (Change widget) the same way, `widget-hooks.openBeside` (every editor's opener: asked before it shows a tab out of sight), `WidgetPopup` (its ×, scrim and Esc, over an editor opened from it), `review-jump` (a jump that hides another tab or closes the popup), and `WorkspacePage`'s route blocker. Only what can't ask leaves an editor with its says-so notice: a data replace, an undo, a typed hash, a cell resized too small for its widget. **The one roster of open editors** (`registerEditorFields`, `closeOpenEditors`, `openOneEditor`): each store that holds a "which editor is open" field registers how its fields close (`ui-store`: Edit list, the Number editor; `chart-widgets-store`: a chart's, Created vs completed's); `closeOpenEditors()` closes them all — Settings opening, the widget popup and a data replace (`refresh-all`) call it — and `openOneEditor(open)` is how each opens: asked first, then every other one closed, so one editor at a time holds across kinds **A layout-wide editor** (`OpenEditor.layoutWide`, the layout edit mode) is asked only when something leaves the layout: `leaveLayout()` asks every editor holding changes — the mode too — then leaves the layout-wide ones holding none (`quitLayoutEditors`, their `leave`); `layoutLeaveAsks()` says whether it would ask. A layout switch, New / Duplicate / delete layout (`workspace-store`), Settings opening (`ui-store.openSettings`) and an in-app route change (`WorkspacePage`'s blocker) use them; everything inside the layout (`afterLeavingEditors`, `leaveOpenEditors`, `editorsHoldChanges` — scope `cell`, the default: a cell's split, merge, insert, close, tab switch, Add widget, the widget popup) passes the mode by, so it never questions its own edits.
